📌 Project Overview
The FHICT-Bot is an autonomous mobile robot designed to demonstrate complex embedded systems principles, including low-level peripheral drivers, Feedback Control Systems (FCS), and IoT-based remote monitoring.

The system utilizes an STM32 (Nucleo) for time-critical motion control and an ESP32 for high-level networking, creating a robust, distributed architecture.

🏗 System Architecture
The robot operates through a layered control approach:

Sensing: Uses an ultrasonic sensor configured via Interrupts to measure obstacle distance with high precision.

Logic (PD Controller): Implements a Proportional-Derivative (PD) controller to achieve smooth braking and prevent overshoot as the robot approaches obstacles.

Actuation: Controls dual servo motors using Pulse Width Modulation (PWM) generated by dedicated STM32 timers (TIM2).

Networking: Bridges the STM32 to an ESP32 to stream real-time speed and distance data to a remote dashboard.
